# 연승 · 정액 수익 연구

`betkj2`의 복연승 수익 연구를 바탕으로 만든 **별도의 연승(PLACE) 전용 앱**입니다. 연승은 경주의 공식 적중 자리 수에 따라 정산하며 단승과 다릅니다.

목표는 선택마다 1,000원을 고정했을 때의 **총 세전 순손익 최대화**입니다. 적중률·단순 ROI 최대화나 복리·추격 베팅을 사용하지 않습니다. 실시간 배당을 수집하지 않으며 과거 확정 배당으로 학습한 예상 환급 배당을 사용합니다.

## 공개 결과

- 2021–2026년 공식 보고서 1,620개, 경주 이력 12,903개에서 **연승 배당 검증 12,899경주**.
- 2021년은 이력 축적, 실제 분석은 11,092경주·115,507개 출전 기록.
- 2022–2024년 학습 → 2025.01–03 보정 → 2025.04–12 조건 선택 → 2026.01–09.10 분리 평가.
- Gamma/Poisson 배당 모델 × 기대수익 문턱 8개 × 경주당 선택 수 3개 × 예상 배당 하한 3개 = 144개 조건.
- 선택 기간 200회·60일 이상, 앞·뒤 시기 각 50회 이상·흑자, 최고 수익일 제외 후 흑자인 조건 중 총 순손익 최대를 선택. 안정 조건이 없으면 최고 순손익 연구 후보를 남기고 실제 추천은 보류.
- 선택된 연구 조건: Gamma 배당 모델, 예상 기대수익 5% 이상·예상 배당 2배 이상, 경주당 최대 2마리.
- 조건 선택 기간: 262회, **−19,500원 (−7.44%)**.
- 2026 분리 평가: 280회, 총 280,000원, **−5,800원 (−2.07%)**. 날짜 재표집 95% ROI 구간 **−22.30% ~ +19.66%**.
- 확률 1위 매 경주 베팅 기준: 1,669회, −265,900원 (−15.93%). 투입 금액이 다르므로 순손익과 ROI 모두 확인해야 합니다.
- **장기 흑자를 입증하지 못했으므로 연구 후보만 표시하고 베팅 추천은 보류합니다.** 베팅하지 않을 경우 순손익은 0원입니다.

## 견고함과 영향도

월·지역·편성 두수·반기·예상 배당 구간, 일별 최대 낙폭, 날짜 재표집 2,500회, 최악 5% 경기일 평균 손익, 환급액 5%/10% 감소, 상위 1건/5건 환급 제거 및 최고 수익일 제외를 공개합니다. 보수적 순손익은 95% ROI 하한×투입금, 10% 환급 스트레스, 상위 5건 환급 제거, 최고 수익일 제외 중 최소값이며 미래 수익의 보장된 하한이 아닙니다.

52개 입력을 사용하는 트리 모델에는 고정된 요소별 선형 가중치가 없습니다. 화면은 **확률 모델과 배당 모델별 교란 영향도**, 실제 확률 보정 계수·배당 보정 배수, 학습률과 모델 구조를 구분해 공개합니다. 영향 비중은 보정 기간 2,500개 출전 기록에서 3회 교란한 손실 증가를 정규화한 설명 지표이며 고정 가중치나 인과효과가 아닙니다. 전체 노드의 분기·잎 값은 `data/model.json`에 있습니다.

실제 확정 배당은 학습 목표 및 정산에만 사용합니다. 같은 날과 미래의 성적은 예측 입력에서 제외합니다. 지난주·지지난주 경기와 재계산 후보, 실제 연승 결과·배당을 함께 볼 수 있습니다. 실제 사전예측 기록 저장 기능은 없습니다.

## 실행과 검증

```bash
pip install -r requirements.txt
OMP_NUM_THREADS=2 python scripts/train_profit.py
node tests/model.cjs
node tests/ui.cjs
python -m unittest discover -s tests -p 'test_*.py'
python -m http.server 8000
```

GitHub Actions의 `site.yml`은 경주 정보·결과를 갱신하고 검증 후 Pages에 게시합니다. `reproduce.yml`은 수동 실행으로 고정 실험을 재현하고 결과를 아티팩트로 보관하며 운영 모델을 자동 교체하지 않습니다. 원본 데이터의 출처 커밋은 `training/provenance.json`, 배당별 보고서 URL·SHA256은 `training/payouts.json.gz`에 보존합니다.

새 저장소에서는 **Settings → Pages → Build and deployment → Source: GitHub Actions**를 한 번 활성화해야 합니다. 이후 `Update and publish PLACE page` 워크플로를 실행하면 됩니다.

## 한계

2026년 자료는 이번 조건 선택에서 제외했지만 이전 연구에서 사용되었으므로 완전히 새 독립 자료는 아닙니다. 과거 화면은 재계산이며 실제 사전 예측 기록이 아닙니다. 공식 배당에 이미 포함된 공제율을 다시 차감하지 않으며 개인별 적중금 세금·입장 비용은 제외한 세전 손익입니다. 해석 불명확·배당 미확인 자료는 미적중으로 처리하지 않습니다. 작은 하위 집단의 흑자를 보고 사후 조건을 변경하지 않았습니다. 비교 범위 내 최적화이며 모든 가능한 전략의 최고 이익이나 미래 흑자를 보장하지 않습니다.
